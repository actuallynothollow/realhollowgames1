Save Data Backup

Download this site’s local storage, this tab’s session storage, and same-origin IndexedDB saves before moving links. Browser security prevents this page from backing up data owned by games on other websites. Backup files may contain private or temporary data; keep them somewhere safe.





To move saves, download the JSON backup, open it in a text editor, copy all its contents, then paste them into the box and choose Restore Pasted Backup at the destination. You can also select the JSON file directly. This includes the active tab’s session storage plus this site’s local storage and same-origin IndexedDB; saves owned by other websites cannot be read here.
